# Security research and responsible disclosure

SOVEREIGN is an independent, scoped security research project.

- **Public research portfolio:** This repository shows selected interface imagery and high-level descriptions. It is not a vulnerability disclosure channel.
- **Sensitive information stays private:** No exploit proof, unpatched vulnerability details, private crash data, research target credentials or device identifiers are intentionally published here.
- **Verification standard:** Unusual behaviour, a software crash, a potential vulnerability and an exploitable security issue have different evidence requirements.
- **Apple reporting:** Any relevant, reproducible issue will be evaluated against the current [Apple Security Bounty guidelines](https://security.apple.com/bounty/guidelines/) before responsible disclosure.
- **No automatic submission:** Neither this repository nor the private project publishes reports without human review.

Please do not post suspected unpatched vulnerabilities or personal data in public discussions. Use an appropriate secure coordinated-disclosure process.
